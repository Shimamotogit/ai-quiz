# UIデザイン方針

確認日: 2026-08-12

このサイトは AI 製品のデモ画面ではなく、**人が会場で動いて答えるライブクイズ**として設計します。AI は出題テーマのひとつであり、UI の装飾モチーフにはしません。VOICEVOX:ずんだもんは音声クレジット上必要な情報ですが、キャラクター色やキャラクターらしさをデザインの中心には置きません。

## 2026-08-12 再調査で確認したこと

### Kahoot!

- ライブゲームでは問題と回答を同時に提示できる。
- タイマー、正誤、スコアなど、クイズの進行状態を明確に分けて見せる。
- 高コントラスト表示など、会場・教室での視認性を意識した設定がある。

参照:
- https://support.kahoot.com/hc/en-us/articles/115016055107-Live-game-settings
- https://support.kahoot.com/hc/en-us/articles/115003197928-How-to-enable-See-questions-on-participant-s-screen-in-Kahoot-live-games

### Mentimeter Quiz Competition

- 問題中は問題とタイマーに集中し、回答後に正答を提示する。
- スコアやリーダーボードはクイズ進行と分離した表示として扱える。
- 競争を作る要素は、常時装飾ではなく「問題・時間・正誤・順位」の状態設計に置かれている。

参照:
- https://help.mentimeter.com/en/articles/4305015-how-to-host-the-quiz-competition
- https://help.mentimeter.com/en/articles/410463-how-to-create-a-quiz-competition
- https://www.mentimeter.com/features/quiz-presentations

### Slido

- クイズを「作る → ライブで回答 → 最後にリーダーボード」のシンプルな流れとして整理している。
- タイマーや競争要素はあるが、プレゼンテーションの内容を邪魔しない構成になっている。

参照:
- https://www.slido.com/features-live-quizzes

### Typeform Knowledge Quiz

- 1つの質問に集中し、回答直後に正誤フィードバックを返す。
- フォーム全体の情報を一度に見せず、その時点で必要な内容に集中させる。

参照:
- https://help.typeform.com/hc/en-us/articles/35170230692756-Create-a-Knowledge-quiz-with-Typeform

これらの製品のブランド表現や色をコピーするのではなく、**「その瞬間に必要なクイズ情報だけを見せる」「問題・回答・正誤・結果を状態として分離する」**という共通原則を採用します。

## 今回の基本原則

1. **カメラ映像をプレイフィールドとして最優先する。**
   - UI は映像を隠す面積を最小化する。
   - 人物の顔・上半身を隠す大型カードを常設しない。

2. **問題文は上部の横長テロップにする。**
   - 画面幅をほぼ全て使用する。
   - 読みやすいレスポンシブ文字サイズを維持し、長文は自然に改行する。
   - 文字量によって表示中のフォントサイズが揺れる動的縮小は行わない。

3. **回答エリアは画面下部22%を基本とする。**
   - 立つ場所の区切りが分かればよく、画面の1/3以上を文字で覆わない。
   - A/B/C等のラベルと色の両方で識別する。

4. **音声UIは字幕・小型プレイヤーとして扱う。**
   - 「読み上げています…」等の長い文章を大型カードで表示しない。
   - 自動再生できない場合の再生ボタンだけは操作可能な大きさを確保する。

5. **解説は別の低いフィードバック帯にする。**
   - 問題バーを縦に膨らませない。
   - 回答後だけ回答レーン上に表示する。
   - 最大高さを設け、長文は帯内でスクロールする。

6. **結果と次ゲームを明確に切り替える。**
   - 「同じ設定でもう一度」を押したら、前回の得点画面を最初に消す。
   - 参加者選択へ戻り、次のゲームを前回結果と混在させない。
   - 前の参加者の得点を表示したまま次の開始案内を流さない。

7. **AI・音声キャラクターを視覚ブランドにしない。**
   - 紫〜青のテック系グラデーション、ネオン、ガラス調、発光を使わない。
   - ずんだもんを連想させる緑をメインブランド色にしない。
   - AIリテラシーは「クイズのテーマ」として小さく表示する。

## デザイントークン

- Page: `#eee9df`（ウォームグレー）
- Surface: `#fffdf8`（暖色系白）
- Ink / Primary: `#172033`（ネイビー）
- Answer red: `#d9544d`
- Answer blue: `#2d6cdf`
- Answer green: `#23845a`
- Focus: `#175cd3`
- Success: `#18864b`
- Danger: `#bf3d36`

## 避ける表現

- 紫・青を中心にしたAIサービス風のグラデーション背景
- backdrop blur / glassmorphism
- ネオン発光
- 文字やカードが人物を大きく覆うレイアウト
- 読み上げ状態を説明する長文パネル
- 常時表示される大きなスコアカード
- キャラクター音声のイメージに引っ張られた緑中心のブランド設計
- 黄色をカード上辺などの常設構造アクセントとして使うこと

## アクセシビリティ

- 色だけで回答や正誤を伝えない。
- フォーカスリングを明示する。
- `prefers-reduced-motion` を尊重する。
- 自動再生制限時には音声プレイヤーを操作できる状態で残す。
- 小さい画面でも問題文・回答文を省略せず読めるようにする。

## 守る既存機能・公開パス

- カメラによる参加者選択・回答位置判定
- 問題JSONと出題ロジック
- 問題 → 回答結果 → 解説 → 結果の音声順序
- `VOICEVOX:ずんだもん` クレジット
- `AUDIO_LICENSE.md` の利用条件案内
- `questions.json`、`images/`、`音声データ_MP3/` の公開URL互換
- 音声ファイルを管理者が差し替えられる運用（固定ハッシュで内容を拘束しない）
