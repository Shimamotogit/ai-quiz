# 音声データについて

このフォルダ以下の MP3 は、リポジトリ管理者の申告に基づき、すべて **VOICEVOX:ずんだもん** で生成された音声です。

> **音声クレジット：VOICEVOX:ずんだもん**

`VOICEVOX:ずんだもん` は、ずんずんPJ が公開している VOICEVOX ずんだもん音源利用規約に記載されたクレジット例と同一の表記です。2026-08-17 に公式規約を再確認しています。

音声を利用・複製・再配布・改変する場合は、このフォルダだけを切り出した場合でも、必ず次の公式規約の最新版を確認して従ってください。

- VOICEVOX ソフトウェア利用規約: https://voicevox.hiroshiba.jp/term/
- ずんだもん音源利用規約: https://zunko.jp/con_ongen_kiyaku.html
- VOICEVOX Q&A: https://voicevox.hiroshiba.jp/qa/

詳細は [`docs/AUDIO_LICENSE.md`](../docs/AUDIO_LICENSE.md) を参照してください。

## ディレクトリ構成

- `01.システム/`：開始、正誤、結果発表などアプリ共通の音声
- `02.問題/`：問題文の読み上げ音声
- `03.問題_補足説明/`：採点後の補足説明音声

問題・補足説明の組み込み音声は、問題番号を3桁ゼロ埋めしたファイル名（例: `027.mp3`）で対応付けます。アプリが参照しているファイル名やディレクトリ名を変更する場合は、対応するコードまたは問題データも同時に更新してください。

## 音声ファイルの差し替え

音声ファイルはリポジトリ管理者が必要に応じて差し替える運用です。このため、ファイル内容を固定する SHA-256 台帳は管理しません。

差し替える場合も、次を維持してください。

- アプリが参照するファイル名とディレクトリ構成
- `VOICEVOX:ずんだもん` のクレジット
- VOICEVOX ソフトウェア利用規約・ずんだもん音源利用規約への準拠

## 再利用時の重要事項

- `VOICEVOX:ずんだもん` のクレジットを、利用者が確認できる場所に表示してください。
- アプリ等で利用する場合は、紹介画面など利用者が確認できる場所にクレジットを置いてください。
- 第三者に音声利用を許諾する場合、その第三者にも適用規約の遵守を求めてください。
- このリポジトリは VOICEVOX またはずんずんPJ の公式配布物・公式監修物ではありません。
- このフォルダ内の MP3 に対して、本リポジトリから公式規約を超える追加の利用許諾を与えるものではありません。
