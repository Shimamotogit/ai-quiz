# 音声データについて

このフォルダ以下の MP3 は、リポジトリ管理者の申告に基づき、すべて **VOICEVOX:春日部つむぎ** で生成された音声です。

> **音声クレジット：VOICEVOX:春日部つむぎ**

春日部つむぎ公式のVOICEVOX利用規約では、利用時のクレジット例として `VOICEVOX:春日部つむぎ` が示されています。2026-08-19 に公式規約を再確認しています。

音声を利用・複製・公開・配布・改変する場合は、このフォルダだけを切り出した場合でも、必ず次の公式規約の最新版を確認してください。

- VOICEVOX ソフトウェア利用規約: https://voicevox.hiroshiba.jp/term/
- 春日部つむぎ公式利用規約: https://tsumugi-official.studio.site/rule
- VOICEVOX Q&A: https://voicevox.hiroshiba.jp/qa/

詳細は [`docs/AUDIO_LICENSE.md`](../docs/AUDIO_LICENSE.md) を参照してください。

## ディレクトリ構成

- `01.システム/`：開始、正誤、結果発表などアプリ共通の音声
- `02.問題/`：問題文の読み上げ音声
- `03.問題_補足説明/`：採点後の補足説明音声

問題・補足説明の組み込み音声は、問題番号を3桁ゼロ埋めしたファイル名（例: `027.mp3`）で対応付けます。アプリが参照しているファイル名やディレクトリ名を変更する場合は、対応するコードまたは問題データも同時に更新してください。

## 音声ファイルの差し替え

音声ファイルはリポジトリ管理者が必要に応じて差し替える運用です。このため、ファイル内容を固定する SHA-256 台帳は管理しません。

差し替える場合も、次を維持してください。

- アプリが参照するファイル名とディレクトリ構成
- `VOICEVOX:春日部つむぎ` のクレジット
- VOICEVOX ソフトウェア利用規約・春日部つむぎ公式利用規約への準拠

## 再利用・再配布時の重要事項

- `VOICEVOX:春日部つむぎ` のクレジットを、利用者が確認できる場所に表示してください。
- 春日部つむぎ公式利用規約では、商用・非商用利用が可能とされています。
- 同規約の禁止事項には `二次配布` が含まれます。生成済みMP3そのものを第三者へ配布する場合は特に注意してください。
- 生成済みMP3をアプリに同梱して公開する形態が `二次配布` に当たるかについて、このREADMEでは独自の解釈で許諾済みとは断定しません。
- VOICEVOX側の規約では、生成音声の利用を他者に許諾する場合の遵守条件も定められています。
- このリポジトリは VOICEVOX または春日部つむぎ運営の公式配布物・公式監修物ではありません。
- このフォルダ内の MP3 に対して、本リポジトリから公式規約を超える追加の利用許諾を与えるものではありません。
